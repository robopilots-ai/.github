# RoboPilots

We train dedicated teams of remote operators on your robot (arms, humanoids, drones, vehicles) and deliver every session as robot-learning data.

**Open tools and lists**

- [Teleop latency calculator](https://robopilots-ai.github.io/teleop-latency-calculator/): estimate the round trip from operator to robot and the control mode it supports, per robot type. Also on [Hugging Face](https://huggingface.co/spaces/robopilots-ai/teleop-latency-calculator).
- [Awesome Robot Teleoperation](https://github.com/robopilots-ai/awesome-robot-teleoperation): a curated list of teleoperation hardware, software, data formats, datasets, papers and services. Corrections and additions welcome.
